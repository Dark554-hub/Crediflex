# Plan de cierre despues del feedback

## Semana 1 - Ajustes de uso real

- Revisar comentarios del cliente.
- Corregir reglas de negocio que no coincidan con su operacion.
- Ajustar textos y botones que generen confusion.
- Afinar credito express.
- Afinar liquidacion anticipada.
- Ajustar comprobante PDF.
- Revisar flujo de cobro desde celular.

## Semana 2 - Preparacion de entrega final

- Revisar permisos y acceso.
- Limpiar datos demo si se va a usar con datos reales.
- Preparar deploy final en Vercel.
- Validar variables de entorno.
- Probar flujo completo con datos reales pequenos.
- Revisar rendimiento en celular.
- Hacer respaldo de base de datos.
- Documentar operacion diaria.

## Criterios para cerrar la version final

- El cliente puede registrar clientes sin ayuda.
- El cliente puede abrir creditos normales y express sin ayuda.
- El cliente puede cobrar desde ruta diaria sin confundirse.
- El cliente puede generar comprobantes.
- El cliente entiende la liquidacion.
- El dashboard muestra informacion util.
- No hay pantallas o botones que sobren para operacion diaria.
